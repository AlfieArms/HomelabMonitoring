
# HomeLab Monitor

A Python-based web dashboard for monitoring and managing a Proxmox home lab cluster.

# Planned Features

- Real-time CPU, RAM and storage monitoring
- Monitor Proxmox nodes, VMs and containers
- Automatically discover new machines
- Responsive dashboard for desktop and mobile
- Historical performance graphs and alerts
- Secure VM management controls

# Stack

- Python
- FastAPI
- Proxmox VE API
- HTML, CSS and JavaScript
